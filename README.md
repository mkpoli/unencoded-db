# 珍字集覽

A community evidence wiki for characters and glyphs. Anyone can create a record with a source URL and view the collection.

A record keeps a character or glyph as a person encountered it, with a source and optional IDS. Whether it is encoded, a variant or a new character is a later question; the collection keeps the evidence for that analysis and for IRG suggestions.

## Local development

Install [Bun](https://bun.sh/), then run:

```sh
bun install
bun run db:local
bun run preview
```

The local D1 database is stored in Wrangler's local state. To run the checks:

```sh
bun run test
bun run check
bun run build
```

The Cloudflare configuration contains a placeholder D1 ID. Provision a database and configure its binding before using a separate environment.

## Limitations

This is a local prototype, not ready for public operation. It has no moderation, abuse prevention, rate limiting, editing, deletion or contributor accounts. Pagination lists 20 records at a time.
