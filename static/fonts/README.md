# Inter

`InterVariable.woff2` is Inter 4.66 from the [Inter project](https://github.com/rsms/inter),
downloaded from `docs/font-files/InterVariable.woff2`. It is licensed under the SIL Open Font
License 1.1; the licence is in `Inter-OFL.txt`. The design system loads it with a variable weight
range so the 500–650 heading weights render as intended.

## IDS operators

`NotoSansCJKjp-ids-operators.woff2` and `Jigmo-ids-operators.woff2` draw the ideographic description
operators U+2FF0–U+2FFF, which the UI fonts fall back to empty boxes for. Both are the subsets
shipped by [ids-input](https://github.com/mkpoli/ids-input); their source and licence details are in
its [font notes](../third-party/ids-input/fonts/README.md).

- Noto Sans CJK JP 2.004, U+2FF0–U+2FFB: © 2014–2021 Adobe, SIL Open Font License 1.1
  ([licence](../third-party/ids-input/fonts/OFL-NotoSansCJK.txt)).
- Jigmo 20250912, U+2FFC–U+2FFF: Koichi Kamichi, CC0 1.0
  ([licence](../third-party/ids-input/fonts/LICENSE-Jigmo.txt)).
